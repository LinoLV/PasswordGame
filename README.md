# **PasswordGame**
PasswordGame is an **OFFLINE** game (Except the web version). \
The goal of the game is to make a password by following the on-screen conditions. All the correct passwords entered will win!🎖️ \
**• Discord Server: https://dsc.gg/forrealserver/** \
**• Website: https://linolv.github.io/**
## **📝Installation**
### Web version:
Simply open https://linolv.github.io/passwordgameweb/ to play the game! \
Web version code can be found here: https://github.com/LinoLV/passwordgameweb/
### For Windows:
Download the .exe file from the [latest release](https://github.com/LinoLV/PasswordGame/releases/latest/) and run the .exe to play!
### For Linux or MacOS:
・The first step is to install wine from https://winehq.org/. _(Skip this step if you already have wine installed)_ \
・The second step is to download the .exe file from the [latest release](https://github.com/LinoLV/PasswordGame/releases/latest/) and run the .exe to play!
### For Android:
Download the .apk file from the [latest release](https://github.com/LinoLV/PasswordGame/releases/latest/), then install the game and open it to play!
> [!NOTE]
> GBoard keyboard users might experience a glitch when editing the password. To fix this, use any other keyboard or only edit your password with the backspace key without selecting/tapping in the password field.
